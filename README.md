# USE

이미지 호스팅용 저장소.

- 주소: `https://hitchik.github.io/USE/<폴더>/<파일>`
- 예시: `https://hitchik.github.io/USE/KU/1.webp`

파일명은 0을 붙이지 않는다. `1.webp`, `10.webp`, `103.webp`

## 폴더

| 폴더 | 장수 |
|---|---|
| BLG | 103 |
| KU | 95 |
| LL | 94 |
| NO | 103 |
| RE | 94 |

`KU`, `LL`, `RE`는 이전에 `HitChiK.github.io` 저장소의 `USE/` 폴더에 있던 파일들이며,
주소가 동일하게 유지되도록 저장소 이름을 `USE`로 맞췄다.
